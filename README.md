# DH307 — Contrastive Learning for Protein–Ligand Screening

Code for the project **"Ligand-Side Gains from a Trained Projection of Frozen DrugCLIP
Atom Embeddings."**

DrugCLIP screens molecular libraries by encoding a protein pocket and a molecule into one
pooled vector each and scoring the pair with a single dot product — discarding the per-atom
token representations its encoders compute. We keep those encoders **frozen**, add a single
trained linear projection on the per-atom tokens, and rerank a shortlist with a
late-interaction (MaxSim) score. The reranker improves early enrichment, but a battery of
controls shows the gain is **predominantly ligand-side** rather than pocket–ligand
complementarity, and that the late-interaction operator is largely not essential.

---

## Repository layout

```
src/         experiment, analysis, and control scripts (run together, flat package)
notebooks/   one-target end-to-end reproduction notebook + its generator
paper/        the report (PDF + LaTeX source)
presentation/ the slide deck
results/      per-target result JSONs behind the report's tables
```

The `src/` scripts are kept in one directory on purpose: several import from
`rerank_eval` / `contact_recover`, so they must sit together.

## Requirements

These scripts are **not standalone**; they run inside the DrugCLIP / Uni-Mol environment.

- [DrugCLIP](https://github.com/bowen-gao/DrugCLIP) + Uni-Mol / Uni-Core, with the released
  `checkpoint_best.pt` (frozen encoder used throughout).
- DUD-E and LIT-PCBA in DrugCLIP's LMDB format (`pocket.lmdb` + `mols.lmdb` per target).
- `rdkit` (scaffolds, conformers); a separate conda env with `openbabel` + `plip` for the
  typed-interaction ground truth.

Run from the DrugCLIP repo root with the usual unicore flags; every script's module
docstring gives the exact command line, e.g.:

```bash
python src/rerank_eval.py --user-dir ./unimol ./data --task drugclip --arch drugclip \
  --loss in_batch_softmax --path ../checkpoint_best.pt --max-pocket-atoms 511 \
  --dude-root <DUD-E>/all --layers 15,14,13,12
```

## Headline results
- **DUD-E (20 held-out):** BEDROC +0.117, EF@0.5% +7.9 (paired-bootstrap significant, 18/20 and 14/20 targets).
- **Ablation:** raw atom cosines (no `W`) *hurt*; the trained projection is the contribution.
- **LIT-PCBA transfer** (`W` trained on DUD-E only): BEDROC +0.0156 at a fixed DUD-E operating point, +0.0233 under LOO-CV.
- **Specificity:** a wrong pocket reranks as well as the correct one; a no-pocket ligand-only head does at least as well — so the gain is predominantly ligand-side, not pocket-specific. The atom-wise maximum is largely not essential (a matched mean ties it on DUD-E; a small significant edge appears only on debiased LIT-PCBA).
- **Deployment utility:** adds ~5 actives@50 / ~9 @100, scaffold-diverse.
- **Contact recovery:** learned correspondences rank true 4 Å contacts above chance (AUROC 0.56–0.60) and survive a generated conformer — a partial signal, not a contact predictor.
